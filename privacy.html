Privacy Policy

Last updated: 31 October 2026

Who uses this app

BumBum Uploader is a personal tool used only by its owner on the owner's own computer. It is not offered to the public.

Google / YouTube data accessed

With the owner's consent, the app uses the YouTube Data API to upload videos and thumbnails to the owner's own channels, set titles, descriptions, tags, privacy status and publish schedules, post and edit the owner's comments on those videos, and read the owner's channel and video information needed for these tasks.

How data is stored and shared

  • OAuth tokens are stored only on the owner's local computer and are never sent to any server other than Google.
  • No data is sold, shared with third parties, or used for advertising.
  • No data about other YouTube users is collected.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
